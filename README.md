# 📚 BookStore App

A simple BookStore web application built with **Node.js**, **Express**, **MongoDB**, and **EJS**.  
Users can sign up, log in, and manage books (add, edit, delete, view).  

---

## 🚀 Features
- User authentication (signup & login with hashed passwords using bcrypt)
- Add new books with title, author, price, and description
- Edit existing books
- Delete books
- Search books by title
- Clean UI with EJS templates

---

## 🛠️ Tech Stack
- **Backend:** Node.js, Express
- **Database:** MongoDB (Mongoose ODM)
- **Templating:** EJS
- **Authentication:** bcrypt for password hashing
- **Environment Config:** dotenv
